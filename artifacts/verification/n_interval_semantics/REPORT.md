## 三、1356 vs 388 的差额拆解（逐条闭合）

| 项 | 数量 | 构成 |
|---|---|---|
| A 表总行 | 1356 | 300 共有 + 1056 A 独有 |
| B 表总行 | 388 | 300 共有 + 88 B 独有 |
| 共有键 | 300 | 五列数值逐字相同，仅 N1/N2 差 1 |
| **A 独有** | **1056** | N2=1 → **970**（91.9%）；N2≥2 → **86**（其中 N1=3 的 **86 条**，非 3 的 **0 条**） |
| **B 独有** | **88** | N1=8 → 47；N2=5 → 44；「N1=8 或 N2=5」去重后 **88**；两者都不占的 **0** |

**A 独有的 1056 条，100% 只能在其中一侧被剔除：**

- 970 条：工作台下标差 N2=1 → **两个涨停相邻** → 按目标定义 N2 = 0 根 K 线 → skill 的 `N2∈[1,5]` 必然不收。
- 86 条：工作台下标差 N1=3 → **中间只有 2 根 K 线** → skill 的 `N1∈[3,8]` 必然不收。

**B 独有的 88 条，正好是同一 off-by-one 的镜像：**

- 47 条 N1=8 → 目标定义中间 8 根 → 工作台需下标差 9 > 上限 8 → 工作台不收。
- 44 条 N2=5 → 目标定义中间 5 根 → 工作台需下标差 6 > 上限 5 → 工作台不收。

即：规则文本里的 `∈[3,8]`、`∈[1,5]` 两侧写的数字一样，但**实际过滤区间错开了一格**：

| 变量 | 文本区间 | 工作台实际接受（中间 K 线数） | skill 实际接受（中间 K 线数） |
|---|---|---|---|
| N1 | [3,8] | 2 ~ 7 | **3 ~ 8** |
| N2 | [1,5] | **0** ~ 4 | **1** ~ 5 |

低端工作台更松（多收中间 0 根 ≈ 连续涨停）、高端工作台更紧（漏掉中间 5/8 根）。
由于「中间 0 根」在真实行情中占比极高（970/1356 = 71.5%），工作台的整体命中数被放大到 skill 的 3.5 倍。
