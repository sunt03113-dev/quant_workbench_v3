## 1. 定位（用识别器实测原文，`rule_10cm.txt`）

改动前 problems（5 条，UI 只显示第一条，易误导为"只是符号约定行不认识"）：

| # | 片段 | 原因 | 实质 |
|---|---|---|---|
| 1 | 符号约定：D-n代表D-0… | 存在暂不支持的条件表述 | 说明行被当条件解析（噪音） |
| 2/3 | (20日)成交额最大 / (20日)股价最高 | 未找到交易日锚点 | 同日多条件用了「;」分隔，锚点 D-y 被切断 |
| 4 | D-y与D-x间隔…N1∈[1,5]… | 暂不支持的条件表述 | **变量日之间的变量间隔，D 记法无此能力** |
| 5 | D-(y+1)~D-(y+5)… | 未找到交易日锚点 | 第二个变量 y 不支持（只有单变量 x） |
| 6 | （全局）2≤x≤11 | 缺取值范围声明 | 原文没写量化范围 |

**结论：这不是措辞问题，是记法体系问题**——「两个变量日 (x,y) + 它们之间的变量间隔 N1/N2」
只有 **T 链记法**（2026-09-21 实装）能表达；D 记法只有单变量 x + 固定相对日。

## 2. 语义映射（D 记法 → T 链记法）

| 原文（D 记法） | 改写（T 链记法） |
|---|---|
| D-y（最早，涨停+20日成交额最大+股价最高） | T_0 涨停 + `T_0的成交额和股价均是近20日最高` |
| D-x（涨停） | T_1 涨停 |
| D-0（信号日，涨停） | T_2 涨停 |
| D-y与D-x间隔N1∈[1,5]，D-x与D-0间隔N2∈[1,5] | `T_0-T_1间隔N1∈[1,5]，T_1-T_2间隔N2∈[1,5]，N1、N2自由组合` |
| 区间内全部不是涨停 | `T_0与T_1间无涨停，T_1与T_2间无涨停` |
| 整个区间仅三日涨停 | `仅T_0、T_1、T_2三日涨停` |
| D-y更早一侧紧邻5日全部不是涨停 | `T_0前5日无涨停` |
| 输出 D-0日期/N1/N2/D-y振幅/D-x振幅/区间涨幅/区间振幅/D-0振幅 | `T_2的日期、T_0与T_1间隔N1、T_1与T_2间隔N2、T_0的振幅、T_1的振幅、T_0~T_2区间涨幅、T_0~T_2区间振幅、T_2的振幅` |
| **输出 D+1~D+8股价走势** | **无对应能力（链式输出暂无前向走势）**——对应 2026-09-20 C6 裁定（前向窗口独立 plan kind 待排期），须从本条去掉，不能硬写（写了整体 fail-closed） |

注意链记法方向约定：**T_0 = 最早锚点，末锚点 = 信号日**；每个满足的 (N1,N2) 组合各出一行。
