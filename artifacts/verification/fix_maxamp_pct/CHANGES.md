# 修复：区间最大振幅输出格式（去掉 % 后缀）

日期：2026-09-21
触发：kk 报告 UI 回测结果「D-x~D-1区间最大振幅」列带 %（截图 0921A 结果），与 Skill 输出规范冲突。

## 规范依据（Skill 源码原文，未修改）
- `0908_backtest.py` L25：「单日涨幅/振幅数值不带 %；区间涨幅/振幅与成交额百分比数值带 %。」
- `B9_backtest.py` L9：「单日振幅不带%，区间涨幅/振幅带%」
- `0803_backtest.py` L12：同口径。

## 语义裁定（kk 2026-09-21）
「区间最大振幅」= 区间内逐日**单日**振幅取最大，本质是单日口径 → **不带 %**。
（区间涨幅 / 区间振幅是跨日聚合口径 → 继续带 %，不变。）

## 根因链
老 Skill `0908_backtest.py` L312 自身将该列格式化为 `f"{...}%"`（与其 L25 规范自相矛盾，
属老系统格式化瑕疵）→ golden 0908/0908B/0908C 继承 → 本执行器照抄 golden 格式。

## 修改（app/executor.py，2 处）
- 主路径 `_build_row`（原 L648-651）：`f"{round(max(amps), 2)}%"` → `round(max(amps), 2)`
- 链式路径 `_build_chain_row`（原 L264-266）：同上
- 备份：`app/executor.v1.baseline.py`（修改前原文）
- SHA-256：before `1589987278FF...C641E8` → after `c048c2a13f00...bdbbdcf`（本目录）
