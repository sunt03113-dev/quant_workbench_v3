# D 记法变量间隔链自动翻译（2026-09-22）

## 问题
用户在 UI 直接提交 121 规则 D 记法原文（含 `D-y~D-0间隔天数为N1∈[3,8]` 这类
**变量日 + 变量间隔**），识别器报「暂不支持」。上一轮只改进了错误提示并给手工
T 链改写稿，用户要的是**原文直接可跑**。

## 方案（kk 口径 2026-09-22）
- `recognizer._translate_dvar_chain`：D 记法出现变量间隔时自动翻译为内部间隔链计划：
  - 变量日按**字母倒序**排布（D-y 比 D-x 更早），D-0 恒为末锚点（信号日）；
  - 相邻端点间隔（如 `D-y与D-x`）→ 直接间隔；跨多段间隔（如 `D-y~D-0`）→
    **跨间隔和约束**（`chain.span_gaps`），未被直接声明的间隔按
    「跨间隔 − 其余已声明间隔」唯一分解（121: g1 = N1−N2 ∈ [1,7]）；
  - 无锚点续行（「成交额最大」「股价最高」）并入当前锚点（修复旧路径 ≤6 字符
    静默丢弃的隐患，仅新路径生效）；
  - 输出段支持键式（`D-y~D-0: 区间涨幅`）与内联式（`D-0的日期、…天数N1`）两种，
    列名保留用户 D 记法书写。
- `executor`：`span_gaps` 组合过滤（N1 = Σ相邻间隔 ∈ [3,8]）；`chain_gap` 输出
  跨间隔变量取和；新增 `chain_walk` 链式前向走势（与量化路径 t_walk 同口径，
  T+0 = 信号日后一交易日，列名 D+1~D+8）；列名 label 支持；`validate_rows`
  独立复核按「跨间隔和 − 已声明间隔」重建内部间隔并校验（SPAN_MISMATCH）。
